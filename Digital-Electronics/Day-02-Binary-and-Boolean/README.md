# Day 2: Binary Number System and Boolean Algebra

## Learning Objectives
Understand binary number representation, decimal-to-binary conversion, and basic Boolean operations.

## Topics Covered

### 1. Binary Number System
- Binary uses two digits: 0 and 1.
- Each binary digit is called a bit.
- Binary is widely used in digital electronic systems.

### 2. Binary to Decimal Conversion

Example:

\[
(1011)_2
\]

\[
=1(2^3)+0(2^2)+1(2^1)+1(2^0)
\]

\[
=8+0+2+1=11
\]

Therefore, (1011)₂ = (11)₁₀.

### 3. Decimal to Binary Conversion

Example:

\[
(10)_{10}=(1010)_2
\]

### 4. Boolean Algebra

Boolean algebra uses two logical values:

- 0 – LOW / FALSE
- 1 – HIGH / TRUE

### 5. Basic Boolean Operations

| Operation | Boolean Expression |
|---|---|
| AND | A · B |
| OR | A + B |
| NOT | A̅ |

## Key Learnings
- Binary numbers use base 2.
- Decimal numbers use base 10.
- AND produces 1 only when both inputs are 1.
- OR produces 1 when at least one input is 1.
- NOT produces the complement of its input.
